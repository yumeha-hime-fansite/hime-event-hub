# 夢羽ヒメ イベントハブ v2 — ゆめかわメモ帳デザイン

ファンサイト用のイベント一覧と、X投稿用の16:9画像・テキストを **1枚のGoogleスプレッドシートから自動表示** する静的サイトです。**普段の画像編集、HTML修正、GitHub操作は不要**になる構成です。

## 初回セットアップ（1度だけ）

### 1. GitHubリポジトリを作る

`yumeha-hime-fansite` アカウントに、公開（Public）リポジトリ `hime-event-hub` を新規作成してください。ZIPを解凍し、**ZIP内のファイルをリポジトリの最上位**へアップロードします（`index.html` が最上位に来る状態）。

`Settings` → `Pages` → `Build and deployment` で `Deploy from a branch` / `main` / `/(root)` を選択します。公開URLは通常、次のとおりです。

- イベント一覧：`https://yumeha-hime-fansite.github.io/hime-event-hub/`
- X用画像・文章：`https://yumeha-hime-fansite.github.io/hime-event-hub/?mode=x`
- Strikingly埋め込み用：`https://yumeha-hime-fansite.github.io/hime-event-hub/?mode=embed`

※ GitHub Pages の公開が有効になるまでURLは開きません。URLを取得後に確認してください。GitHubへのアップロード・公開はこの配布物では実施していません。

### 2. 元イラストをそのまま配置する

GitHubの `assets/` に**ご自身で権利・公開許可を確認した元の透過PNG**を配置してください。

- `assets/hime-left.png`：サイト上部とX画像1枚目の左イラスト
- `assets/hime-right.png`：サイト上部とX画像1枚目の右イラスト
- `assets/hime-left2.png`：X画像2枚目以降の左イラスト
- `assets/hime-right2.png`：X画像2枚目以降の右イラスト

元のイラストは**AIで生成・再描画・学習・加工しません**。HTMLでは `<img>` として読み込み、PNG出力でも同じ元画像を縦横比を保って描画します。**このZIPにはキャラクターイラストは含まれません**。元イラストを置くまでは装飾的な記号だけを表示します。

Publicリポジトリに置いたファイルは一般公開され、第三者も取得できます。公開許諾があるものに限ってください。

### 3. Googleスプレッドシートを用意する

1. Googleスプレッドシートでイベント情報**専用**の新規ファイルを作ります。
2. メニューの **ファイル → インポート → アップロード**で `sheet-template.csv` を取り込みます。1行目の英語の列名は変更しないでください。2行目以降は**すべて架空のサンプル**なので、実際の情報に入れ替えます。
3. 共有 → 一般的なアクセスを「**リンクを知っている全員 → 閲覧者**」にします。**編集者として共有しない**でください。個人情報や非公開情報を含めないでください。
4. スプレッドシートのURLを確認します。`https://docs.google.com/spreadsheets/d/【sheetId】/edit#gid=【sheetGid】`
5. リポジトリの `config.js` の `sheetId: ''` と `sheetGid: '0'` を、上記IDに書き換えます。**これが初回の唯一の設定変更**です。
6. 必要であれば同じ `config.js` の `siteUrl` にStrikinglyサイトの正しい公開URLを設定します（X投稿文の先頭に掲載します）。
7. 公開サイトを再読み込みして実際のデータが表示されることを確認します。データは閲覧のたびにGoogle Sheetsの公開ビューから取得するため、**シートを編集するたびにGitHubのファイルを更新する必要はありません**。反映にはGoogle側のキャッシュによる遅延が起こる場合があります。

> 技術仕様：Google Charts Visualization の公開スプレッドシート `gviz/tq` をJSONPで取得しています。認証を必要とする非公開シートは読み取れません。またGoogle側の仕様・公開権限・利用制限の変更で取得できなくなる場合があります。その際はApps ScriptやGitHub Actionsによる同期へ切り替えてください。

### 4. Strikinglyに埋め込む

既存のStrikinglyの有料プランで使える「HTML」セクションに、`strikingly-embed.html` の**中身をコピーして貼り付け**ます。イベント欄へ入れると、一覧部分だけが表示されます。

- Strikingly本体のページは置き換えません。
- イベント件数に応じて `<iframe>` の高さを調整するスクリプトが付属しています。Strikinglyの仕様でスクリプトが無効になった場合は、`height:980px` を必要な高さに調整し、内部スクロールで利用してください。
- 既存の手動更新の記事欄と二重掲載しないように、移行後は手動更新部分を削除または案内用リンクへ変更することを推奨します。

## 普段の運用（ここだけ！）

1. 新情報が出たらGoogleスプレッドシートに**1行追加**します。
2. イベント一覧が自動で表示されます。期限切れは自動非表示、取り下げる場合は `show` を `FALSE` にします。
3. Xへ投稿するときは `?mode=x` を開き、**「PNG保存」**と**「文章をコピー」**を押します。長いときは自動分割された**投稿ごとのコピーボタン**も使えます。記事を書く際にCanvaなどを開く必要はありません。

## 入力する列

| 列名 | 内容・例 |
|---|---|
| `category` | ライブ、イベント、キャンペーン、グッズ、配信、その他 |
| `title` | イベント名（必須） |
| `start_date` | 開催・販売開始日：`2027-01-16` |
| `end_date` | 開催・締切日：`2027-01-16`。過ぎると自動非表示 |
| `date_label` | 定期枠の自由表示：`毎週水曜`（常設なら日付列は空欄） |
| `time` | `20:00` |
| `place` | 秋葉原、YouTubeなど |
| `summary` | X画像で短く伝えたいこと（現在はイベント日・場所を優先して表示） |
| `details` | サイトとX投稿本文に載せたい詳しい説明 |
| `url` | 詳細案内の公式URL |
| `priority` | 1が最優先、9が低優先 |
| `show` | `TRUE`なら掲載、`FALSE`なら非掲載 |

### 表示ルール

- X画像は1ページ最大8件（4カテゴリ枠×各2件）。カテゴリごとの掲載数が多い場合は自動でページを増やします。
- 画像にはイベント名、日付、場所をコンパクトに表示。リンク・注意事項はX投稿文とサイトに記載します。非常に長いタイトルは画像で省略し、サイト・本文に全文を残します。
- 期限切れの判定は日本時間で行います。**締切日の当日は表示**し、翌日から非表示にします。
- Google Sheetsの公開設定が未完了、または読み込み失敗時はエラーを表示し、**架空のデモ情報で置き換えません**。`sheetId` が空のときに限って、明示したデモを表示します。
- X本文の全文と、**約260文字以内を目安に自動分割したスレッド案**を併記します。実際のXの文字数計算は記号・リンクなどで異なる場合があるので投稿前に確認してください。Xの自動投稿機能はありません。

## デザインと画像について

- 今回採用した **「ゆめかわメモ帳系」** をベースに、メモ帳・マスキングテープ・手書き風のライン・パステルのラベンダー／ピンクで構成しました。
- Webの文字には無料のGoogle Fonts `Zen Maru Gothic` / `Yomogi` を利用します。ネットワーク・閲覧環境により標準フォントに切り替わる場合があります。
- キャラクター画像は上記のファイルをそのまま読み込みます。ブラウザ上でサイズを変更して表示するだけで、画像ファイルそのものは変更しません。
- PNG書き出しはブラウザのCanvas APIで1600×900を生成します。初回はフォントと画像が読み込まれるまで待ってから保存してください。端末によっては複数ファイルの一括ダウンロードが制限されます。

## 追加仕様（2枚目の画像差し替え）

- X用画像の**1枚目**は `hime-left.png` / `hime-right.png` を使用します。
- X用画像の**2枚目以降**は `hime-left2.png` / `hime-right2.png` を優先して使用します。
- `hime-left2.png` / `hime-right2.png` がない場合は、1枚目と同じ画像を使います。
